Onboard an API

Submit a new API onboarding request and track it through validation, approval and deployment.

You can:

  • provide the required API configuration
  • upload and validate an OpenAPI specification
  • save a draft and return later
  • track onboarding progress

Manage onboarding requests

Review API onboarding requests, assign an owner and update the status visible to delivery teams.

Authorised ICC team members can:

  • view submitted requests
  • update validation and approval status
  • record actions and review notes
  • mark deployments as completed or failed

Request access to the portal

You need a local portal account before you can use the API onboarding or ICC admin journey.

To request access, include:

  • your first name, last name and email address
  • why you need access to the portal
  • whether you need to onboard a new API or manage an existing API
